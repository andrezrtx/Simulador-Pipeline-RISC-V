¿Qué representa cada etapa?

IF — Instruction Fetch

Busca la instrucción indicada por el PC. Un cambio de flujo puede descartar instrucciones que se habían buscado por el camino equivocado.

ID — Instruction Decode

Decodifica la instrucción y lee registros. La unidad de detección de hazards puede detener aquí la instrucción si necesita esperar.

EX — Execute

La ALU calcula operaciones y direcciones. La unidad de forwarding puede tomar resultados de etapas posteriores sin esperar a WB.

MEM — Memory access

Realiza lecturas y escrituras de memoria para lw y sw. Una carga puede provocar un hazard si la siguiente instrucción usa el valor recién cargado.

WB — Write back

Escribe el resultado en el registro destino cuando la instrucción produce uno.

Flush / excepción

Flush invalida instrucciones más jóvenes. En el ejemplo de excepción, se vacía el camino especulativo y se muestra el salto al manejador ilustrativo.

Nota académica: es un simulador didáctico, no un modelo RTL exacto de una CPU concreta. Las decisiones de branch y los valores de registros se simplifican para que se vea el comportamiento del pipeline.
